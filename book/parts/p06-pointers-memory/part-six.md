## اشاره‌گرها
- آدرس حافظه، عملگرهای `&` و `*`
- رابطه‌ی اشاره‌گر و آرایه
- Pointer arithmetic
- اشاره‌گر به‌عنوان پارامتر تابع
- اشاره‌گر به اشاره‌گر
- void pointer و function pointer

- Memory leak و dangling pointer
- آرایه‌ی پویا
