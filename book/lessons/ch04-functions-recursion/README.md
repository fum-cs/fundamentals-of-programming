# فصل ۴: توابع و بازگشت

- `lecture.md` / `.ipynb`: درسنامه
- `supplementary.md` / `.ipynb`: مباحث تکمیلی
- `exercises.md` / `.ipynb`: تمارین (با راهنمایی و پاسخ تاشو)
- `src/`: همهٔ برنامه‌های C (کامنت‌ها انگلیسی)؛ با `./build_all.sh` همه را کامپایل کنید
- `images/`: تصاویر فصل

## یک کار دستی: عکس آلونزو چرچ
`lecture.md` به `images/alonzo-church.jpg` اشاره می‌کند. این فایل را در `images/` بگذارید
(از Wikimedia Commons، مثلاً با جست‌وجوی «Alonzo Church»؛ مجوز و نام عکاس را بررسی کنید).

## نوت‌بوک‌ها
در `lecture.ipynb` و `supplementary.ipynb` کدها سلول اجرایی‌اند (`%%writefile` و `gcc`) و خروجی آن‌ها ذخیره شده است. پوشه‌های `src` و `bin` هنگام اجرا ساخته می‌شوند. در `exercises` کدِ پاسخ‌ها داخل بلاک‌های تاشو و ثابت است.
